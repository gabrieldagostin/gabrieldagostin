## Featured Project

### 🎮 ARS.io — Independent Game Distribution Platform

ARS.io is a platform concept focused on helping independent game developers publish and manage their games while allowing users to discover, acquire, and access indie games.

The project is being developed with a focus on modular architecture, maintainable code, and a multi-platform experience.

**Planned / current technology stack**\

-  **Backend**: Java, Spring Boot
-  **Frontend**: React, TypeScript, Vite
-  **Desktop Application**: Electron
-  **Database**: PostgreSQL
-  **Caching**: Redis
-  **Object Storage**: MinIO
-  **Reverse Proxy**: Nginx
-  **Architecture**: Modular Monolith, with clear module boundaries
-  **Database Migrations**: Flyway
-  **Testing**: JUnit, Mockito, Testcontainers
-  **Containerization**: Docker, Docker Compose

> Project status: in development. Some technologies and features may
> still be planned rather than implemented.

[View the repository](https://github.com/gabrieldagostin/arsio)
